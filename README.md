# Concept Automation Technologies

Official web application for **Concept Automation Technologies** — Importer, exporter, and supplier of industrial factory automation products including PLCs, HMIs, VFDs, Servo Drives, and Automation Accessories in Ahmedabad, India.

Reference website: https://www.conceptautotech.com/

## Key Features
- **Comprehensive Product Catalog**: Detailed listings for Siemens, Mitsubishi, Allen Bradley, Omron, Delta, Schneider, Proface, Danfoss, and Fuji automation components.
- **Dark & Light Mode**: Built-in dynamic theme switcher.
- **Inquiry & Lead System**: Direct product inquiry modal and contact form.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- **Framework**: TanStack Start & React
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Database / Auth**: Supabase

## Local Development

### Prerequisites
- Node.js (v18+) or Bun / npm / pnpm

### Setup
1. Clone the repository:
```sh
git clone https://github.com/jiya1218/Concept-automation.git
cd Concept-automation
```

2. Copy environment variables:
```sh
cp .env.example .env
```

3. Install dependencies and start dev server:
```sh
npm install
npm run dev
```

4. Build for production:
```sh
npm run build
```
